# ArchadiAgent Documentation

ArchadiAgent is a from-scratch, provider-agnostic TypeScript SDK for building tool-using, multi-agent LLM systems — plus a CLI you can run immediately by forking this repo.

You should not need to read the SDK source to use it. Start here:
